# CodeAlpha Student Grade Tracker

A console-based Student Grade Tracker developed in Java as part of the CodeAlpha Java Programming Internship.

## Project Description

This project manages student marks and generates a grade report. It calculates average marks, identifies the highest and lowest marks, and assigns grades based on student marks.

## Features

- Add student details
- Enter student marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Identify highest scorer
- Identify lowest scorer
- Generate student grade report
- Validate marks between 0 and 100

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
